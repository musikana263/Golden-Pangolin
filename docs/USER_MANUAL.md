# Part 1 — For Visitors

## 1. The Homepage

When someone arrives at **goldenpangolin.com** they see:

- A large hero section with a featured tour package and a brief introduction
- A **"Featured Destinations"** strip showing handpicked locations
- A **"Curated Packages"** section with the top tour packages
- A **"Hand-Picked Accommodation"** section with our top stays
- A blog teaser and a contact call-to-action

Everything on the homepage is automatically curated based on what an admin has marked as featured.

## 2. Choosing Your Traveller Type

The first time someone visits the site, a small bar appears at the bottom asking:

> *"I'm travelling from…"*

with three options:

- **Local traveller** (Zimbabwean residents)
- **Regional traveller** (other African nationals)
- **International traveller** (everyone else)

This choice tells the site which prices to show, and which activities and packages are available to that visitor. Each traveller type may see a slightly different lineup — some experiences are offered to all groups, others only to specific ones.

The choice is remembered for a year. Visitors can change it any time using the small **icon in the top navbar** (a house, globe, or plane depending on their current selection).

## 3. Browsing Destinations, Packages, and Accommodation

The top menu has three main browsing options:

### Destinations
Each destination has its own page showing:
- A description of the place
- Activities you can do there
- Packages featuring that destination
- Nearby accommodation

### Packages
A list of curated multi-day tour packages. Click any package to see the full itinerary, what's included, and the price.

### Accommodation
A list of hotels, lodges, and tented camps. Click any one to see:
- Photos (tap a photo to open the full gallery — swipe left/right to view the rest)
- Full description
- Amenities
- An "Enquire on WhatsApp" button that opens a pre-filled WhatsApp message

## 4. The Wishlist (Heart Icons)

Visitors can tap the **♥ heart icon** on any package, activity, or accommodation to save it for later.

- The hearts appear on every card
- A red heart count appears in the top navbar showing how many items are saved
- Click the heart in the navbar at any time to see the full wishlist
- From the wishlist page, visitors can **send their entire wishlist to us on WhatsApp** with one tap — useful for asking for a quote on multiple items at once

No account is needed — the wishlist is saved in the visitor's browser.

## 5. Light & Dark Mode

A small **sun/moon icon** in the top navbar lets visitors switch between light mode (cream and gold) and dark mode (black and gold). Their choice is remembered for next time.

## 6. Contacting Us

The **Contact** page has a form for sending us a message. It also shows:
- WhatsApp phone number (clickable to open WhatsApp directly)
- Email address
- Office location

A floating green WhatsApp button is shown on every page so visitors can chat with us instantly.

## 7. Reading the Blog

The **Blog** page lists all our travel stories and tips, with the most recent ones first. Each post can be opened individually to read the full content.

# Part 2 — For Administrators

This part covers everything you can do once you log into the admin dashboard. **Only verified admin accounts can access these pages.**

## 1. Logging In

Go to **goldenpangolin.com/login** and enter your email and password. If you've forgotten your password, click **"Forgot your password?"** to receive a reset link by email.

After logging in, depending on your security settings, you may be asked to enter a one-time code (sent to your email). Type the code to finish logging in.

## 2. The Dashboard

The dashboard is the first page you see after logging in. It shows:

- A welcome banner with today's date
- **Quick stat tiles**: number of destinations, categories, packages, stays, blog posts, and users
- **Quick action buttons** — shortcuts to add a new destination, blog post, category, or accommodation
- **Recent destinations** and **Recent blog posts** — the most recently added items
- **Recent activity timeline** — a feed of the latest changes to the site

From the left-hand menu you can jump to any management section.

## 3. Managing Destinations

A **destination** is a place — Victoria Falls, Hwange, Lake Kariba, etc. Each one has its own page on the public site.

### Adding a Destination
1. Click **"+ Add New Destination"** from the dashboard or the destinations menu
2. Fill in:
   - **Title** (e.g. "Victoria Falls")
   - **Country** (defaults to Zimbabwe)
   - **Description** — what visitors see on the destination page
   - **Image** — the main photo
   - **Publish date** — when this becomes visible (usually leave it as today)
3. Click **"Create"**

### Editing or Deleting
On the destinations list, each row has an edit button (pen icon) and a delete button (trash icon). Deleted destinations go to the **Trash** — they can be restored from there for a limited time before being permanently deleted.

### Reordering
You can drag and drop the rows on the destinations list to change the order they appear on the public site. The order you set there is the order visitors see.

## 4. Managing Categories

**Categories** are used to group blog posts and activities by theme (e.g. "Safari", "Cultural", "Adventure"). You need at least one category before you can write blog posts.

### Adding a Category
1. From the menu, click **Categories → Add new**
2. Enter the **name** and an optional **description**
3. Save

Categories can be edited and deleted from the categories list.

## 5. Managing Activities

**Activities** are individual things to do at a destination — boat cruises, game drives, helicopter flights, etc.

### Adding an Activity
1. Click **Activities → + Add new**
2. Fill in:
   - **Activity name**
   - **Destination** — pick which destination this activity belongs to
   - **Category** — optional
   - **Duration** (e.g. "2 hours", "Half day")
   - **Pricing mode** — pick ONE of:
     - **Fixed**: one price for everyone (enter the price)
     - **Free**: no charge for anyone
     - **Tiered**: different price per traveller type
       - Leave a tier blank to **hide** the activity from that group
       - Set a tier to **0** to mark it **free** for that group
     - **From…**: a free-text label like "From $50 per person" (used when the exact price varies a lot)
   - **Park / conservation fee** (optional checkbox) — tick if there's an extra fee like Victoria Falls park entry, then enter the amount
   - **Short description** — one or two sentences shown on the destination page
   - **Photos** — up to 3 photos
   - **Visible on public site** — leave ticked to show; untick to temporarily hide

3. Click **"Create Activity"**

### Reordering
On the activities list, drag and drop rows to set their display order.

## 6. Managing Accommodation

**Accommodation** entries are hotels, lodges, tented camps, and similar.

### Adding Accommodation
1. Click **Accommodation → + Add new**
2. Fill in:
   - **Name**
   - **Type** — pick from accommodation types (Lodge, Hotel, Tented Camp, etc.)
   - **Location** (e.g. "Victoria Falls")
   - **Country**
   - **Description**
   - **Price From** — a free-text price label (e.g. "From $250 per night")
   - **Amenities** — tick the boxes for WiFi, pool, restaurant, etc.
   - **Photos** — up to 6 photos
   - **Visible on public site**

3. Save

### Managing Accommodation Types
The **types** (Lodge, Hotel, Tented Camp, etc.) are managed under **Accommodation Types** in the menu. You can add, edit, or delete types — each one can have an icon and a description.

### Reordering
Drag and drop rows to set the order shown on the public site. This order also applies to the "Where to stay near…" section on destination pages.

## 7. Managing Packages

**Packages** are multi-day tour bundles — itineraries that combine destinations, activities, and an accommodation.

### Adding a Package
1. Click **Packages → + Add new**
2. Fill in:
   - **Name**
   - **Destinations** — add as many as the package covers (use the "+ Add destination" button to add more rows)
   - **Activities** — add the activities included in this package
   - **Short description**
   - **Duration** (e.g. "7 Days / 6 Nights")
   - **Group size** (e.g. "2-10 People")
   - **Price** — free-text price (e.g. "From USD 1,890 per person")
   - **Accommodation** — optional, link to one of your accommodations
   - **Image** — the main package photo
   - **Visible on public site** — leave ticked to show
   - **Featured package** — tick to make it appear in the homepage "Curated Packages" section
   - **Show this package on the homepage hero** — only ONE package can hold this slot at a time. Ticking it automatically un-ticks any other package currently in the hero slot.
   - **Available to** — three checkboxes for which traveller types can book this package (Local / Regional / International). Tick all three (default) to offer it to everyone. Untick to hide it from those visitors. If a hero package isn't available to a visitor's tier, the site automatically picks a different one for them.

3. Save

### Reordering
Drag and drop rows on the packages list.

## 8. Writing Blog Posts

### Adding a Blog Post
1. Click **Blog → + Add new** (or the "Write Blog Post" shortcut on the dashboard)
2. Fill in:
   - **Title**
   - **Category**
   - **Short description** — the teaser shown in lists
   - **Content** — the full article
   - **Image** — the post's cover photo
   - **Publish date** — when it becomes public
3. Save

### Reordering
Blog posts can be dragged and dropped to reorder. Newer posts default to the top.

## 9. Re-ordering Items (Drag and Drop)

Many lists (destinations, activities, accommodation, packages, blog posts) support **drag-and-drop reordering**:

1. Hover over any row — you'll see a "grip" handle on the left side
2. Click and hold the grip, then drag the row up or down to a new position
3. Release — the new order saves automatically

The order you set is what visitors see on the public site.

## 10. The Trash Bin

Whenever you delete a destination, package, accommodation, or blog post, it goes to **Trash** first — it isn't permanently removed.

Click **Trash** in the menu to see everything that's been deleted, grouped by type. From there you can:

- **Restore** — brings the item back to life as if it was never deleted
- **Delete permanently** — wipes the item and its photos for good

Items in trash are not visible on the public site, but they're still recoverable.

## 11. Managing Users

The **Users** page lists everyone who has an account on the site. From here you can:

- See each user's name, email, and role (Admin / regular user)
- Edit their details
- Promote a user to admin (so they can also manage the site)
- Demote an admin back to a regular user
- Delete a user

You can also add new admin accounts from this page.

## 12. Site Settings

The **Settings** page lets you change site-wide options like:

- **WhatsApp number** — the number used by the floating chat button and "Enquire" buttons
- **Email addresses** — where contact form messages are sent
- **Social media links** — Facebook, Instagram, TikTok
- **Other branding and contact info**

Changes here apply across the entire site.

# Helpful Things to Know

## Picture Sizes

The site automatically **shrinks large photos when you upload them** — you can drop in a 5 MB photo from a phone or camera and the site will resize it for fast loading. You don't need to compress images yourself.

## Image Tips

- Use **landscape** photos (wider than tall) where possible — they look better in card layouts
- The first photo you add becomes the cover photo
- For activities and accommodation, the rest of the photos cycle in a gallery on the public page

## Visibility Toggles

Most items (destinations, activities, packages, accommodation) have a **"Visible on public site"** switch. Untick this to **temporarily hide** something without deleting it. Useful when:
- You're still working on a draft
- A package is seasonal and not currently bookable
- You need to take something down briefly without losing the content

## If You Make a Mistake

- Almost every delete goes to **Trash** first — you can restore from there
- For text changes, just edit and save again
- If something looks wrong on the public site, check that **"Visible on public site"** is ticked, and that everything has a photo and description

## Getting Help

If something isn't working or you're stuck, take a screenshot and contact the developer — having the actual screen makes it much faster to fix.
